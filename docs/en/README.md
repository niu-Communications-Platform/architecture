# Architecture Documentation — English translation

This directory contains the maintained English translation of the canonical German architecture documentation in `docs/de/`.

The German version is the source of truth. English documents should indicate whether their translation is current, outdated, or not yet available.

## Structure

The directory structure mirrors `docs/de/`:

- `00-product/`
- `10-system/`
- `20-hardware/`
- `30-software/`
- `40-audio/`
- `50-networking/`
- `60-identity-security/`
- `70-provisioning-lifecycle/`
- `80-manufacturing/`
- `90-ux-ui/`

Product-specific implementation details belong in the corresponding product repositories unless they define or affect platform-wide architecture.
